# Curriculum: Python for AI, from zero

A 90-day path, one lesson a day. Each phase builds on the one before; later lessons assume the earlier ones are done.

## Phase 1 — Python foundations (days 1–20)

| Day | Topic |
| --- | --- |
| 1 | Hello, Python: running code, `print`, comments, values and variables |
| 2 | Numbers and math: `int`, `float`, operators, `round`, `//` and `%` |
| 3 | Strings: indexing, slicing, methods, f-strings |
| 4 | Input and type conversion: `input`, `int()`, `float()`, `str()` |
| 5 | Booleans and comparisons; `if`, `elif`, `else` |
| 6 | `while` loops, `break` and `continue` |
| 7 | Lists: creating, indexing, changing, list methods |
| 8 | `for` loops, `range`, `enumerate`, `zip` |
| 9 | Tuples and sets |
| 10 | Dictionaries |
| 11 | Functions: `def`, parameters, `return` |
| 12 | Functions deeper: defaults, keyword arguments, `*args`, `**kwargs`, scope |
| 13 | Comprehensions: list, dict and set |
| 14 | Errors and exceptions: reading tracebacks, `try` / `except` / `raise` |
| 15 | Files: reading and writing text, `with`, `pathlib` |
| 16 | Modules and the standard library: `math`, `random`, `datetime`, `collections` |
| 17 | Classes and objects |
| 18 | Classes deeper: inheritance, dunder methods, `dataclasses` |
| 19 | Iterators, generators and `lambda` |
| 20 | Mini project: a command-line study tracker |
