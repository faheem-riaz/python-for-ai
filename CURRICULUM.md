# Curriculum: Python for AI, from zero

A 40-day path, one lesson a day. Each lesson covers two or three related topics, so plan for about an hour a day: 30–40 minutes of reading and 20–30 minutes of exercises. Each phase builds on the one before; later lessons assume the earlier ones are done.

## Phase 1 — Python foundations (days 1–11)

| Day | Topic |
| --- | --- |
| 1 | Hello, Python: running code, `print`, comments, values and variables |
| 2 | Numbers and strings: `int`, `float`, operators, `round`, `//` and `%`; indexing, slicing, string methods, f-strings |
| 3 | Input and decisions: `input`, type conversion, booleans, comparisons, `if` / `elif` / `else` |
| 4 | Loops: `while`, `for`, `range`, `enumerate`, `zip`, `break` and `continue` |
| 5 | Collections: lists, tuples and sets |
| 6 | Dictionaries and comprehensions (list, dict and set) |
| 7 | Functions: `def`, parameters, `return`, defaults, keyword arguments, `*args`, `**kwargs`, scope, `lambda` |
| 8 | Errors and files: tracebacks, `try` / `except` / `raise`; reading and writing text with `with` and `pathlib` |
| 9 | Modules, the standard library (`math`, `random`, `datetime`, `collections`), iterators and generators |
| 10 | Classes: objects, inheritance, dunder methods, `dataclasses` |
| 11 | Mini project: a command-line study tracker |

## Phase 2 — Tools of the trade (days 12–14)

| Day | Topic |
| --- | --- |
| 12 | Virtual environments, `pip` and `requirements.txt`; Jupyter notebooks |
| 13 | JSON, calling web APIs with `requests`, type hints |
| 14 | Testing with `pytest`; mini project: a tested API client |

## Phase 3 — Data with NumPy and pandas (days 15–20)

| Day | Topic |
| --- | --- |
| 15 | NumPy arrays: creating, shapes, `dtype`, indexing, slicing, boolean masks |
| 16 | NumPy maths: vectorised operations, broadcasting, aggregations and axes |
| 17 | pandas: Series and DataFrames, loading CSV and Excel, selecting rows (`loc`, `iloc`, conditions) |
| 18 | Cleaning and combining: missing values, types, duplicates, `groupby`, merging and joining |
| 19 | Dates and time series, text columns, reshaping with `pivot` and `melt` |
| 20 | Mini project: exploring a real dataset |

## Phase 4 — Visualisation and the maths behind ML (days 21–24)

| Day | Topic |
| --- | --- |
| 21 | matplotlib: line, bar and scatter plots, histograms and distributions |
| 22 | Linear algebra with NumPy: vectors, dot products, matrices, matrix multiplication |
| 23 | Statistics and probability: mean, variance, standard deviation, sampling |
| 24 | Derivatives and gradients, intuitively; gradient descent from scratch |

## Phase 5 — Machine learning with scikit-learn (days 25–31)

| Day | Topic |
| --- | --- |
| 25 | What machine learning is; linear regression; train/test split and regression metrics |
| 26 | Classification: logistic regression, accuracy, precision, recall, confusion matrix |
| 27 | More models: k-nearest neighbours, decision trees, random forests, gradient boosting |
| 28 | Preprocessing: feature scaling, encoding categorical data, pipelines |
| 29 | Model selection: cross-validation, hyperparameter tuning, overfitting and regularisation |
| 30 | Unsupervised learning and text: k-means, PCA, bag of words and TF-IDF |
| 31 | Mini project: an end-to-end classifier |

## Phase 6 — Deep learning with PyTorch (days 32–35)

| Day | Topic |
| --- | --- |
| 32 | Tensors, autograd and a neural network from scratch |
| 33 | `nn.Module`, layers, activations, loss functions, optimisers and the training loop |
| 34 | Datasets and DataLoaders; image classification with CNNs; saving, loading and evaluating models |
| 35 | Transfer learning and attention, intuitively; mini project: fine-tune a small model |

## Phase 7 — LLMs and AI applications (days 36–40)

| Day | Topic |
| --- | --- |
| 36 | How LLMs work (tokens, context windows, sampling); calling an LLM API; prompt design and system prompts |
| 37 | Structured output (JSON) and streaming responses |
| 38 | Embeddings, semantic search and retrieval-augmented generation (RAG) |
| 39 | Tool use and agents; evaluating AI features; cost, latency and safety |
| 40 | Final project: your own AI app |
